# Bugs

## Современный Supabase secret key отклоняется при запуске Python-клиента

- Причина: закреплённый `supabase==2.15.1` проверяет ключ как JWT и отклоняет непрозрачные ключи `sb_secret_…` до HTTP-запроса.
- Исправление: минимальное обновление до `supabase==2.16.0` в зависимостях бота и ручных импортов. Обработчики, запросы, таблицы и Storage-пути не изменены.
- Проверка: offline-тест конструктора SDK для modern secret, publishable и legacy JWT с запрещённой сетью.
- Production: до merge в upstream `main`, новых сборок и отдельной ротации прежние значения ключей сохраняются.

## Публичный ключ Vite остаётся внутри прежней сборки

`VITE_SUPABASE_ANON_KEY` встраивается в JS при `npm run build`. После изменения публичного ключа нужна новая сборка и обновление страницы в браузере. README описывает порядок; серверный ключ во фронтенд не переносится.
